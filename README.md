## 📝 Descrição
Aplicativo desenvolvido em **React Native** com **Expo** para servir como um cartão de visitas digital. O foco principal foi a implementação de navegação moderna e organização de componentes básicos.

## 🛠️ Tecnologias & Bibliotecas
- **Framework:** React Native + Expo
- **Navegação:** React Navigation (Bottom Tabs)
- **Ícones:** Expo Vector Icons (Ionicons, FontAwesome, MaterialCommunityIcons)
- **Estilização:** StyleSheet (CSS-in-JS)

## ✨ Funcionalidades
- **Barra de Navegação Flutuante:** UI customizada com efeito de profundidade e bordas arredondadas.
- **Card de Perfil:** Identificação rápida com links para redes sociais.
- **Grid de Habilidades:** Lista interativa de tecnologias dominadas, utilizando ScrollView para melhor experiência.
- **Link Externo:** Integração com o repositório GitHub via `Linking` API.
